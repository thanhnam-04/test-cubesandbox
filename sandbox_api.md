# Sandbox creation and management
| Method   | API                     | URL / URI                                        | Request body / query                                                                                                                                                                                                      | Success return                                                                                                                                       |
| -------- | ----------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `POST`   | Create sandbox          | `{CUBE_API_URL}/sandboxes`                       | JSON. `templateID` required. Optional `timeout`, `lifecycle`, `secure`, `allow_internet_access`, `network`, `metadata`, `distributionScope`, `envVars`, `mcp`, `volumeMounts`. `envs` is accepted as alias for `envVars`. | `201` `Sandbox`, including `templateID`, `sandboxID`, `clientID`, `envdVersion`, optional `alias`, `envdAccessToken`, `trafficAccessToken`, `domain` |
| `GET`    | List sandboxes          | `{CUBE_API_URL}/sandboxes`                       | Query: `metadata` optional                                                                                                                                                                                                | `200` array of sandbox records                                                                                                                       |
| `GET`    | List sandboxes v2       | `{CUBE_API_URL}/v2/sandboxes`                    | Query: `metadata`, `state`, `limit`, `nextToken`                                                                                                                                                                          | `200` array of sandbox records                                                                                                                       |
| `GET`    | Get sandbox             | `{CUBE_API_URL}/sandboxes/{sandboxID}`           | None                                                                                                                                                                                                                      | `200` sandbox details                                                                                                                                |
| `DELETE` | Kill sandbox            | `{CUBE_API_URL}/sandboxes/{sandboxID}`           | None                                                                                                                                                                                                                      | `204`, no body                                                                                                                                       |
| `POST`   | Pause sandbox           | `{CUBE_API_URL}/sandboxes/{sandboxID}/pause`     | None                                                                                                                                                                                                                      | `204`, no body                                                                                                                                       |
| `POST`   | Resume sandbox          | `{CUBE_API_URL}/sandboxes/{sandboxID}/resume`    | JSON; `{}` valid. Optional `timeout`, `autoPause`                                                                                                                                                                         | `201` `Sandbox`                                                                                                                                      |
| `POST`   | Connect / auto-resume   | `{CUBE_API_URL}/sandboxes/{sandboxID}/connect`   | JSON; `{}` valid. Optional `timeout` in API model                                                                                                                                                                         | `200` `Sandbox`                                                                                                                                      |
| `POST`   | Set idle timeout        | `{CUBE_API_URL}/sandboxes/{sandboxID}/timeout`   | `{"timeout": number}`                                                                                                                                                                                                     | `204`, no body                                                                                                                                       |
| `POST`   | Refresh lifecycle       | `{CUBE_API_URL}/sandboxes/{sandboxID}/refreshes` | `{"duration": number}`                                                                                                                                                                                                    | `204`, no body                                                                                                                                       |
| `GET`    | Sandbox logs            | `{CUBE_API_URL}/sandboxes/{sandboxID}/logs`      | Query: `start`, `limit`                                                                                                                                                                                                   | `200` logs                                                                                                                                           |
| `GET`    | Structured sandbox logs | `{CUBE_API_URL}/v2/sandboxes/{sandboxID}/logs`   | Query: `cursor`, `limit`, `direction`                                                                                                                                                                                     | `200` structured logs                                                                                                                                |
| `POST`   | Create snapshot         | `{CUBE_API_URL}/sandboxes/{sandboxID}/snapshots` | JSON; `{}` valid, or `{"name":"..."}`                                                                                                                                                                                     | `201` with `snapshotID` and `names`                                                                                                                  |
| `GET`    | List snapshots          | `{CUBE_API_URL}/snapshots`                       | Query: `sandboxID`, `limit`, `nextToken`                                                                                                                                                                                  | `200` snapshot array; continuation token in `x-next-token`                                                                                           |
| `POST`   | Roll back sandbox       | `{CUBE_API_URL}/sandboxes/{sandboxID}/rollback`  | `{"snapshotID":"..."}`                                                                                                                                                                                                    | `200` with `sandboxID`, `snapshotID`, `operationID`, `status`                                                                                        |
| `DELETE` | Delete snapshot         | `{CUBE_API_URL}/templates/{snapshotID}`          | None                                                                                                                                                                                                                      | Successful deletion; snapshot is internally represented as a template                                                                                |

# Sandbox process operation
| Method | API                  | URL / URI                                                       | Request body                                                                                               | Return                                                            |
| ------ | -------------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| `POST` | List processes       | `http://49983-{sandboxID}.{domain}/process.Process/List`        | `{}`                                                                                                       | `{"processes":[...]}`                                             |
| `POST` | Start process        | `http://49983-{sandboxID}.{domain}/process.Process/Start`       | `{"process":{"cmd":"...","args":[...],"envs":{...},"cwd":"..."},"pty":...,"tag":"...","stdin":true/false}` | **Streaming** `ProcessEvent`: `start`, `data`, `end`, `keepalive` |
| `POST` | Connect to process   | `http://49983-{sandboxID}.{domain}/process.Process/Connect`     | `{"process":{"pid":number}}` or `{"process":{"tag":"..."}}`                                                | **Streaming** `ProcessEvent`                                      |
| `POST` | Update process       | `http://49983-{sandboxID}.{domain}/process.Process/Update`      | `{"process":{...},"pty":{"size":{"cols":number,"rows":number}}}`                                           | `{}`                                                              |
| `POST` | Send process input   | `http://49983-{sandboxID}.{domain}/process.Process/SendInput`   | `{"process":{...},"input":{"stdin":"<base64>"}}` or `{"input":{"pty":"<base64>"}}`                         | `{}`                                                              |
| `POST` | Stream process input | `http://49983-{sandboxID}.{domain}/process.Process/StreamInput` | Framed stream starting with `start`, followed by `data` / `keepalive`                                      | `{}` when stream terminates                                       |
| `POST` | Send signal          | `http://49983-{sandboxID}.{domain}/process.Process/SendSignal`  | `{"process":{...},"signal":"SIGNAL_SIGTERM"}` or `"SIGNAL_SIGKILL"`                                        | `{}`                                                              |
| `POST` | Close stdin          | `http://49983-{sandboxID}.{domain}/process.Process/CloseStdin`  | `{"process":{...}}`                                                                                        | `{}`                                                              |

# Filesystem metadata operation
| Method | API                | URL / URI                                                                  | Request body                                            | Return                                           |
| ------ | ------------------ | -------------------------------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------ |
| `POST` | Stat               | `http://49983-{sandboxID}.{domain}/filesystem.Filesystem/Stat`             | `{"path":"..."}`                                        | `{"entry": EntryInfo}`                           |
| `POST` | Make directory     | `http://49983-{sandboxID}.{domain}/filesystem.Filesystem/MakeDir`          | `{"path":"..."}`                                        | `{"entry": EntryInfo}`                           |
| `POST` | Move / rename      | `http://49983-{sandboxID}.{domain}/filesystem.Filesystem/Move`             | `{"source":"...","destination":"..."}`                  | `{"entry": EntryInfo}`                           |
| `POST` | List directory     | `http://49983-{sandboxID}.{domain}/filesystem.Filesystem/ListDir`          | `{"path":"...","depth":number}`                         | `{"entries":[EntryInfo,...]}`                    |
| `POST` | Remove             | `http://49983-{sandboxID}.{domain}/filesystem.Filesystem/Remove`           | `{"path":"..."}`                                        | `{}`                                             |
| `POST` | Watch directory    | `http://49983-{sandboxID}.{domain}/filesystem.Filesystem/WatchDir`         | `{"path":"...","recursive":true/false}`, Connect-framed | **Streaming** `start`, `filesystem`, `keepalive` |
| `POST` | Create watcher     | `http://49983-{sandboxID}.{domain}/filesystem.Filesystem/CreateWatcher`    | `{"path":"...","recursive":true/false}`                 | `{"watcherId":"..."}`                            |
| `POST` | Get watcher events | `http://49983-{sandboxID}.{domain}/filesystem.Filesystem/GetWatcherEvents` | `{"watcherId":"..."}`                                   | `{"events":[...]}`                               |
| `POST` | Remove watcher     | `http://49983-{sandboxID}.{domain}/filesystem.Filesystem/RemoveWatcher`    | `{"watcherId":"..."}`                                   | `{}`                                             |

# File content operation
| Method | API                | URL / URI                                                                 | Request                                                                     | Return                                            |
| ------ | ------------------ | ------------------------------------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------- |
| `GET`  | Download/read file | `http://49983-{sandboxID}.{domain}/files?path={path}&username={username}` | Query: `path`, optional `username`, `signature`, `signature_expiration`     | `200 application/octet-stream`, raw file contents |
| `POST` | Upload/write file  | `http://49983-{sandboxID}.{domain}/files?path={path}&username={username}` | `application/octet-stream` body, or `multipart/form-data` with field `file` | `200` JSON array of `EntryInfo`                   |
| `POST` | Compose files      | `http://49983-{sandboxID}.{domain}/files/compose`                         | JSON containing `source_paths`, `destination`, optional `username`          | `200` destination `EntryInfo`                     |
